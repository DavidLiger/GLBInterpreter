    « Ouvrir dans Blender » lance Blender sur blender/<scène>.blend du livre ouvert, à part : ni suivi, ni journal, jamais arrêté par le studio (« Tout arrêter et quitter » compris). Le gabarit (GLBI_ROOT, empty de cible, lampe Sun, réglages d’export) est copié en blender/<scène>.blend à l’ajout d’une scène et par « Créer depuis le gabarit », jamais par-dessus un fichier existant ; sans gabarit, rien n’est créé.

        Studio arrêté
        
    
        Tous les processus gérés sont arrêtés. Pour relancer le studio : double-clic sur studio.cmd (ou npm run studio) ; cette page se reconnecte alors toute seule.
        
        

  
        Studio ouvert dans un autre onglet
        
    
        Un seul onglet du studio est actif à la fois : celui-ci est en veille. Fermer cet onglet, ou le reprendre ici (l’autre passe alors en veille).
